More better? More happier? You only need one comparative.

If an adjective already becomes better, happier, easier or faster, don't add more in front of it. The comparative is already doing the job.

By Jason Phillips · British English Coach · Published 26 September 2026 · 6 min read
The quick rule:
Say better, not more better. Say happier, not more happier. Say easier, not more easier. In standard English, you normally use either -er or more — not both.

Why “more better” sounds wrong

A comparative already means that one thing has a greater degree of a quality than another. When you say better, the comparison is already built into the word.

Wrong: This option is more better.

Natural: This option is better.

Adding more gives you a double comparative. It is similar to saying the same grammatical idea twice.

more better
better
more happier
happier
more easier
easier
more faster
faster

When do we use -er?

Short adjectives often form the comparative with -er and the superlative with -est.

fast → faster → fastestMy new laptop is faster than my old one.
small → smaller → smallestThis office is smaller than the one downstairs.
cheap → cheaper → cheapestThat was the cheapest option.

Once the adjective has the -er ending, you do not normally add more.

What about happier?

Adjectives ending in -y usually change the y to i before adding -er or -est.

happy → happier → happiest

easy → easier → easiest

busy → busier → busiest

So you would say:

  • I'm happier in my new job.
  • This exercise is easier than the last one.
  • Monday is usually our busiest day.

Not more happier, more easier or most busiest.

When do we use more?

Longer adjectives usually keep their original form and use more for the comparative and most for the superlative.

professional → more professional → most professionalHer second presentation sounded more professional.
confident → more confident → most confidentHe seems more confident in meetings now.
interesting → more interesting → most interestingThat was the most interesting part of the discussion.

We do not normally say professionaler, confidenter or interestinger.

Good is different: good → better → best

Good is irregular. It does not become gooder or more good.

good → better → best

This version is better than the first one.

That was the best answer in the interview.

Because better is already the comparative form, more better is unnecessary in standard English.

Superlatives have the same problem

Learners sometimes double the superlative too:

most happiest
happiest
most easiest
easiest
most fastest
fastest
most best
best

Again, choose one comparative system. If the word already has -est — or it is an irregular form like best — you do not normally add most.

But what if I want to emphasise it?

This is where learners often reach for more better. You can make the comparison stronger, but use an intensifier instead:

It's much better.

I'm far happier now.

This version is a lot easier to understand.

The new process is considerably faster.

These sound natural because much, far, a lot and considerably strengthen the comparison without creating a second comparative.

A simple way to remember it

Before you use more, look at the adjective. If it already says -er, or it is an irregular comparative such as better or worse, the comparison is already there.

happier = already comparative

better = already comparative

faster = already comparative

more professional = needs more because the adjective itself does not change

Quick practice

Correct these sentences before checking the answers:

  1. This phone is more cheaper than mine.
  2. I'm more happier with the new schedule.
  3. Her second presentation was more confident.
  4. This is the most easiest way to explain it.
  5. The new system is more efficient than the old one.

Answers:

1. This phone is cheaper than mine.

2. I'm happier with the new schedule.

3. Her second presentation was more confident.

4. This is the easiest way to explain it.

5. The new system is more efficient than the old one.

The takeaway

Do not make your English more complicated than it needs to be.

More better → better.
More happier → happier.
Most easiest → easiest.

Use -er/-est or more/most according to the adjective. If you want extra emphasis, say much better, far happier or a lot easier.
